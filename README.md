# NextentCreator - AI驱动的内容创作工作流

> 基于多Agent协作架构的智能内容创作平台

## 🎯 项目概述

本项目是一个基于多Agent协作架构的AI内容创作平台，支持图文、技术文档、社交分享等多种内容类型的智能生成。系统采用 **HTML + PHP + Python** 技术栈，通过6个专门的AI Agent协同工作，实现从需求输入到成品输出的全流程自动化。

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                     Web Frontend (HTML/CSS/JS)               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    PHP API Gateway                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  Python Agent Core (多Agent系统)              │
│  意图识别 → 任务分发 → 专项创作(图文/技术/社交) → 润色优化     │
└─────────────────────────────────────────────────────────────┘
```

## 🤖 Agent 系统

| Agent | 职责 | 输出 |
|-------|------|------|
| 意图识别Agent | 解析用户需求，确定内容类型 | 结构化任务描述 |
| 任务分发Agent | 分发任务到对应专项Agent | Agent选择+上下文 |
| 图文创作Agent | 长图文内容创作 | Markdown文章 |
| 技术创作Agent | 技术文档/教程创作 | 技术文档+代码 |
| 社交创作Agent | 短内容/社交帖子创作 | 多版本文案+标签 |
| 润色优化Agent | 质量把关和风格优化 | 最终成品 |

## 🚀 核心亮点

### 1. 核心痛点解决
- 内容创作耗时长、灵感枯竭
- 多平台内容需要反复调整格式
- 难以持续产出高质量内容

### 2. 多Agent协作流程
- **长链推理**：需求分析 → 结构设计 → 内容生成 → 风格适配 → 质量检查
- **Agent间协作**：意图识别 → 任务分发 → 专项创作 → 润色优化
- **智能路由**：根据内容类型自动选择最优Agent组合

### 3. 量化成果
- 内容创作效率提升 80%+
- 支持3大内容类型、10+细分场景
- 端到端自动化，从选题到输出一站式完成

## 🛠️ 技术栈

- **前端**: HTML5 + Tailwind CSS + Vanilla JS
- **API网关**: PHP 8.x
- **Agent核心**: Python 3.11 + FastAPI
- **LLM**: 支持多种大模型API接入
- **知识库**: ChromaDB / JSON

## 🚀 快速开始

### 1. 配置 API 密钥

```bash
# 复制配置模板
cd NextentCreator/config
cp .env.example .env

# 编辑 .env 文件，填入你的 API Key
# 支持的 LLM: OpenAI, Claude, 文心一言, 通义千问, DeepSeek
```

**详细配置说明**: 请查看 [API 配置指南](docs/API_CONFIGURATION.md)

### 2. 启动 Python Agent 服务

```bash
cd backend/agents
pip install -r requirements.txt
python main.py
```

服务启动后访问: `http://localhost:8000`

### 3. 配置 PHP 环境

- 使用 XAMPP/WAMP 等 PHP 环境
- 将项目放入 web 目录
- 访问 `http://localhost/NextentCreator/frontend/index.html`

### 4. 开始使用

- 选择内容类型（图文/技术/社交）
- 输入创作主题
- 点击"开始创作"，观看多 Agent 协作流程
- 获取生成的内容
